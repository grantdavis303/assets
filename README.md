## Good CSS

A lightweight, plug-and-play stylesheet for clean, consistent styling.

1. Use the CDN

```html
<link rel="stylesheet" href="https://d2fwvgwkmab2g5.cloudfront.net/Good.css" type="text/css" />
```

2. Use the Local File

```html
<link rel="stylesheet" href="./Good.css" type="text/css" />
```
